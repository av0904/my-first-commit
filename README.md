# My First Commit 🚀

This is my first GitHub repository.

I created this project to practice the basics of Git, GitHub, commits, and repository structure.

## Purpose

This repository is a small learning project for practicing simple Git and GitHub workflows.

## What this repository contains

* `hello.txt` — a hello-world style file used for first commit practice
* `info.txt` — a practice file for learning how to add and update files
* `proof.txt` — a public proof file used to practice updates and changes

## What I learned

* How to create a GitHub repository
* How to add files
* How to make commits
* How to update existing files
* How to organize a simple repository
* How to write a basic README file
